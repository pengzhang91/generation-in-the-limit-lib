## Shared model and comparison conventions

A family is countably indexed, and every source language is infinite. Finite nonempty families can be repeated along natural indices. An empty family is not represented by a total natural-indexed family with values in it; results about such families are an elementary vacuous extension, not supplied by those binders. The source universe is a countable string domain, canonically positive naturals for density. Lean's zero-based finite-history convention has t observations `s(0),…,s(t−1)` before output t. This corresponds to source round n after n observations by an index shift; the asymptotic claims do not prescribe a finite convergence rate.

Noise counts rejected positions divided by elapsed sample count. Finite noise is finite bad positions in Lean; for injective main streams this equals the source's finite set of invalid values. Vanishing means convergence to zero. Constant noise means an eventual exact `≤c` bound, not merely `limsup≤c`; the latter distinction matters at the critical boundary. Arbitrary omissions mean infinitely many observed target values, not infinitely many missing values. Finite omissions are finite target-minus-range; c-omissions concern canonical lower density of the surviving subset, not a fraction of missing time steps. Completeness is only required when a full presentation is explicitly assumed.

`OrderedLanguage` consists of an infinite carrier and an arbitrary injective enumeration onto it. Its lower and upper densities count the first n elements of that enumeration. Most selected results therefore generalize the source's common ambient increasing order to individually supplied orders. Specializing to induced increasing orders recovers the source convention. The conversion theorem separately requires increasing ambient order, because it chooses the smallest natural output. A supplied arbitrary order must never be described as automatically canonical in the paper's sense.

Element density measures the set of all outputs over the entire run, not a frequency of successful output rounds. Set upper density is the time limsup of **inner lower** ordered density; set lower density is the corresponding time liminf. Both numerical parameters `ρlow` and `ρup` in the transfer are lower guarantees. All finite-prefix mistakes disappear from these density limits, but earlier outputs remain forbidden for element freshness. No output is required to remain absent from future input.

Source element generators avoid observed values and all earlier outputs at every round; source set generators avoid observed values at every round. The existential facade usually packages freshness only eventually, so that its bare proposition is weaker concerning the initial segment. Native named Algorithm Four and Algorithm Eight have separate all-round double-freshness theorems; named set generators subtract the observed prefix in their defining values. This is principally a facade packaging distinction for those constructions, and must not be mistaken for a newly proved global property of an arbitrary existential witness. Global infinite set output on every finite history is an additional conclusion or assumption in several Lean types; source set generators need not all have that property.

A history function is causal by type. A function depending mathematically on the entire collection may use arbitrary predicates, choices, infinitude, exact densities, and convergence cutoffs. This matches a semantic existence treatment of the source's broad collection-oracle model, but it is not a formal machine or oracle-reduction theorem. Exact Boolean membership fields do not prove relative computability. In particular, the finite-expansion oracle field is defined by classical membership in the expanded set, not by an exported operational reduction using only the base query. The membership-only computability claim must be assessed separately. No probability distribution, loss, sample complexity, or stochastic support assumption is present in these 13 targets; the paper's statistical discussion is background and must not be inserted as a hypothesis.
