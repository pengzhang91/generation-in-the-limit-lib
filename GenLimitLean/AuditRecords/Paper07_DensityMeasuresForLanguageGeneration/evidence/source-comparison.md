## Independent source inventory and model

The global convention is stronger than bare countability: every language considered is infinite, U is countably infinite, and K belongs to a countably listed family X (p.1/PDF3). The adversary hides K's identity but enumerates all its elements. The membership black box answers whether w belongs to Li (Definition 2.1, p.6/PDF8). The paper explicitly studies generation *via a function*, excluding computability as the central distinction (p.7/PDF9). Thus classical choices, whole-language containment tests or semantic ranks in Lean do not by themselves violate the source's information model. No runtime, effective oracle reduction, decidable containment, probabilistic loss or sample-complexity rate is promised.

Element validity means eventual output in K minus the observed sample St; Definition 2.2 momentarily states membership alone, but the following bullets and Section 5 restore freshness. Index validity means eventual hypothesized language inclusion in K. The threshold can depend on the entire adversarial presentation. Accurate means extensional equality with K, allowing duplicate indices; the first index z of K is used in proofs (p.8 footnote 3/PDF10). Section 4 locally uses distinct languages. The source describes algorithms both as f_X(St), apparently depending on the finite observed set, and as chronological procedures using the latest observation and previous critical chain. That tension is preserved as a question, not silently resolved.

Relative upper/lower density counts L among the first N elements of the independently ordered reference language L', then takes limsup/liminf (p.4/PDF6; Definition 4.1, p.16/PDF18). The reference must be infinite. This differs from ambient integer density and from validity frequency in time. Index results permit inconsistent language orderings (p.17/PDF19); element results impose a common string order (p.24/PDF26). Section 6 codes that order increasingly into Nat and uses the ordered successor. The paper's O initially excludes off-K outputs, whereas Section 5 uses all outputs; intersection with K leaves these density measurements unchanged, and validity makes the off-K difference finite.

## Nine target dossiers

### 1. GenLimit.KleinbergWei.DensityMeasures.Results.theorem_2_1

Short Lean name: `D.Results.theorem_2_1`; native `D.theorem_2_1` and `D.theorem_3_1` in InfinitelyOften, with `proposition_3_4` in Accurate and `proposition_3_5` in InfinitelyOften. Facade anchor: Results/Overview:26. Source: Theorem 2.1 p.8/PDF10 and Theorem 3.1 p.13/PDF15, supported by pp.14-16/PDF16-18.

The exact skeleton is forall C,s,z, Presents s (C z) -> FirstOccurrence C z -> [exists T forall t>=T, C(guessIndex C s t) subset C z] AND [forall t exists r>=t, C(guessIndex C s r)=C z]. T can depend on the presentation; r also depends on the requested time. The selector takes neither z nor a presentation certificate. Accuracy is language equality, not eventual stabilization at z. The two conjuncts must be retained together.

Directly expanded, Language=Set Nat, C:Nat->Language, Presents=range equality, and the sample contains indices i<t. At t+1, guessIndex uses sample length t and new input s(t). StrictCritical compares only earlier consistent indices i<n. The finite scoped focus uses indices<=t; the boundary branch chooses the last prior critical language containing the new input. This matches the previous-step mechanism in Section 3 after zero-based indexing, with an explicit default 0 for initially empty searches. The source's displayed X_n quantifier includes n and would require Ln properly below itself; Lean follows its immediately following i<n explanation. That is an explicit source normalization, not a literal match to the contradictory displayed definition.

The family can contain finite or empty members; Presents permits repetition and excludes an empty target but permits finite nonempty targets. These broaden the source's all-infinite setting. They do not manufacture an element generator from possibly empty guesses. On source-domain families, infinite guessed languages would permit fresh selection, but that corollary is not a conjunct here. FirstOccurrence is a canonicalization assumption available by choosing the least equivalent index, with native leastEquivalentIndex support; it does not give the algorithm hidden target knowledge. No uniform numerical rate or computability is asserted. The detailed source algorithm is faithfully represented; equivalence to a function of the unordered sample alone remains a source-model question.

### 5. GenLimit.KleinbergWei.DensityMeasures.Results.theorem_6_2_finite_rank_endgame

Short name: `D.Results.theorem_6_2_finite_rank_endgame`; native `F.corollary_6_10`, Fallback:350. Facade: Overview:31. Source: Corollary 6.10 p.39/PDF41, within Theorem 6.2's pp.34-41/PDF36-43 argument.

On the closed finite derivatives of this Hausdorff topology this matches the source finite empty-kernel rank hypothesis; it does not encode arbitrary transfinite rank. Nonempty range C excludes r=0. current contains sample(q+1), next sample(q+2), and their languages are the guesses at q+1 and q+2. These offsets preserve causal previous/current-step use. The source's all-infinite condition is unnecessary for this language-selection conclusion and is not assumed here.

### 7. GenLimit.KleinbergWei.DensityMeasures.Results.theorem_6_12_finite_accounting

The recursive machinery's conditions matter. RunSpec.mk requires every C(n) infinite and takes arbitrary input, arbitrary current:Nat->FamilyPoint C, arbitrary infinite reservationLanguage per Edge, and a finite duplicate-free edge list at every time. It does not require current to equal A_acc, edges to be the source's descending critical-chain gaps, reservation languages to be the designated fallback languages, or the whole rule to depend only on the observed prefix. `RunDemand` is the sigma of a round and an edge in the supplied edge list; historicalPairFamily/runTokenSource prove real pair provenance and token uniqueness for that demand type. Thus a generic recursive process and a token source are present. Instantiating them with the source algorithm while preserving its causal and validity guarantees remains necessary.

Schedule.mk additionally assumes fresh-at-reservation tokens, consumption before deadlines, agreement of token/output positions, priority comparisons, token positions no larger than bad keys, and keys absent from outputs. The capacity constructors accept this schedule plus key-position and output-membership links. They do not manufacture the schedule for the actual retained bad intervals. Schedule.charge_injectiveOn_inputFirst and its output-first counterpart give two injections; Schedule.charge_injective requires the extra NoCrossCollision predicate. This is an explicit native separation of what is sufficient for 1/10 and what is needed for a single injection.

There is also a semantic difference to establish before identifying a reservation run with the paper: the ledger's forbiddenRange is used strings union *all previously reserved strings*. Fresh allocation avoids this whole history, ensuring global string uniqueness. The source fallback list can re-include the same unused string at different fallback events. This stronger reservation discipline may be useful, but equality with the source's queue process and the resulting charging obligations need evidence. Names suggesting historical charging do not establish that equivalence.

For finite rank, the native all-infinite rank-two counterexample states that the same child language has a top ancestor at round 0 but loses that ancestry at round 1 while the top remains consistent. It refutes an unrestricted persistence inference for these forests. It does not assert that these children are the exact A_acc guesses in the density argument, nor that Claim 6.11 or Theorem 6.2 is false. FrozenFrame provides a sound-looking statement-level alternative: pull later consistent points back into one origin forest and climb there under explicit common-ancestor/escape premises. A proof that the actual sequence of bad intervals supplies these premises, and then the counting conclusion, is still required. This is the difference between local repair infrastructure and a completed source theorem.

## Discrepancies, source questions and Stage 1 corrections

The main coverage gaps are distinct. Missing facade wrappers include already-native eventual counting and global-injection 1/8 variants, topology packaging and further consequences of exact accuracy. Missing native assembly includes combining actual fresh output, eventual fallback containment and queue clearance into a theorem about eventual token validity. Missing mathematical bridges include adversarial thin-tower forcing; breadth/truth-index optimality; the lazy upper-density algorithm; long-bad-run-to-climb for changing finite forests; and the general algorithm's retained-run schedule/injection. These should not all be called the same kind of incompleteness.

The source itself raises unresolved questions, fixed independently before Lean access:

1. Definition 3.1 p.14/PDF16 quantifies X_n including Ln but requires strict containment. Immediately following prose uses i<n. Lean adopts that prose reading. Lemma 3.3's proof discusses earlier strict subsets although arbitrary earlier languages not containing K also need elimination; exhaustive presentation supplies the broader argument, but the printed proof is not certified here.
2. The source says f_X(St), then uses chronology. It also varies the displayed freshness convention and does not explicitly formalize repetition in presentations. Lean's repeating total streams and explicit previous-step selection must be compared to the detailed model, not assumed equivalent to an unordered-set function. These are model questions, not evidence of an ineffective algorithm bug.
3. Theorem 5.1 p.25/PDF27 displays exists A forall c<1, implying upper density at least 1/2 for one A. Theorem 2.5 and its proof use forall c exists A. These differ in witness dependency; no native theorem settles either reading.
4. Definition 4.2's epsilon slack does not justify inferring infinitely many densities<=epsilon from breadth<=epsilon exactly, as the converse proof does on p.22/PDF24. A slack argument may recover the intended threshold theorem, but that is additional reasoning, not a silently corrected quote. Theorem 4.9 item 2 also omits explicit validity despite its surrounding optimization among valid algorithms.
5. The p.34/PDF36 level paragraph calls a point in Yi a limit point of X^(i) and then isolated there. The latter follows the displayed Yi definition; native levels follow that definition. The finite proof shifts W to M and r+1 to r in its counting prose. Its cross-forest climb needs a separate persistence argument, as the native diagnostic confirms for an unrestricted version.
6. Lemma 6.16's proof pp.48-51/PDF50-53 passes from injectivity of the unordered-pair map Phi to injectivity of the final output charge rho. Distinct pairs alone need not be disjoint, and even disjoint pairs can charge the same output when one pair is input-first and another output-first. The final proof does not explicitly establish the needed exclusion. Native two-class injections and NoCrossCollision expose a sufficient extra obligation; they do not prove the paper's lemma false. Chronological precedence is also stronger than the purely positional charge certificates used by the density endgame.
7. The p.47/PDF49 retained-mass display uses a maximum where a uniform lower bound over interval ratios is needed. The elementary >=1/2 per non-singleton interval can independently justify the intended bound. Early output sets asserted contained in K in the same proof need a suffix/finite-exception treatment because validity permits early hallucinations.
8. Example 4's ordering of all rational-disc points by coordinate absolute-value sum does not specify an order of type Nat; Example 5 similarly needs an actual reference ordering for its density assertion. Example 9's displayed recursive expression is independent of k despite the subsequent union over k. These examples are not silently repaired or treated as disproving the headline theorem.

Stage 1's principal reconstructions agree with the directly inspected types. Three refinements are needed. First, its target-5 statement that fallback “may be empty” is false for a returned value of this defined fallbackChoice with consistent representatives: the nonempty observed sample lies in next or in its chosen ancestor. Second, its accurate account of the nine-target boundary is not a census of native coverage; the supplement reveals actual output recursion, queue freshness, eventual counting, global-injection 1/8 routes and history bridges. Claims that these objects simply do not exist would overstate the gap. Third, the target-9 all-prefix identity implies an actual disjoint cover along K, although it does not identify those categories with good/bad strings from a run. The missing issue is semantic realization, not partition arithmetic.

The absence of a computability or oracle interface in the targets is not a source-correspondence failure: p.7/PDF9 expressly allows arbitrary functions. The actionable unresolved issues are whether each full source algorithm can be instantiated causally, whether the required schedule/climb hypotheses hold for every exhaustive presentation, and whether the source's suspect proof steps can be supplied or require changed statements. This audit leaves those as questions. It does not infer false main theorems from gaps in their printed arguments or from conditional Lean endgames.
