## Source and representation conventions

The independent inventory records each source claim, all standing assumptions and grouped appendix components. In brief: C01 rules out timely lower density for eventually consistent generators under every deadline; C02 does so under O(i) deadlines even with vanishing expected hallucination; C03 constructs randomized half-density generation under feasible superlinear deadlines with an eventual expected-rate budget; C04 obtains deterministic half upper density at identity deadlines with eventual consistency.

Source Section 1.1 uses one fixed universe preference order, inherited by every language, adversary-first rounds, total enumerations that may repeat, and fresh outputs. The expected hallucination definition has the limit inside the instance suprema; its barrier and positive bound put suprema outside the asymptotic statement. These quantifiers must remain distinct.

Lean uses sets of naturals, range-equality presentations and injective exhaustive language orders. Equal languages must share the same enumeration, but different languages need not restrict a common global order. This generalizes the source ordered-family model. FirstOccurrence is a least-representative condition and is automatic for the source’s bijectively indexed collection of distinct languages. Infinitude is explicit in OrderedLanguage. Finite-set counting agrees with source indicator counting when the target order is injective; repeated output values are deduplicated. The arbitrary-sequence helper theorems can be more general without representing a whole generation theorem.

There is a real deadline-index qualification. With R(j)=k_{j+1} and S(q)=o_{q+1}, the source condition “among the first D(j+1) outputs” becomes q<D(j+1). Thus the source identity deadline transports to j+1. The supplied formal identity is j, and OnTimeUnusedRank requires t<r. It is stricter by one round under this direct transport. It is not enough to dismiss this as a finite-prefix change: outputs at their own deadline can affect every rank. A lower bound for the stricter metric implies a lower bound for the relaxed metric, but an exact-density witness for the stricter metric need not retain equality after relaxation. No exact reindexing/credit-equivalence bridge was found in the inspected interfaces.

Both source and Lean operate with abstract language access. Lean makes full-language subset tests, classical choices and real comparisons explicit. Native prefix-invariance and online-output equality support causal sequential use for C04. Neither source nor interfaces supply ordinary Turing computability or per-round computational cost; “time” means a round.

## Eight target dossiers

**T1 — `Results.theorems_1_2_pathwise_counting_core` (C01/C02), decl:67, Overview:49.** For arbitrary α,S,R,L,T,i,t, if every S(k) for k≥T lies in L, then |R[0,i)∩S[0,t)|≤|R[0,i)∩L|+T. **T2 — `Results.appendix_D_rate_core` (C03), decl:61, Overview:72.** Under monotone naturally superlinear D with eventual strictness, nonnegative antitone H→0 and D⁻¹=o(tH), it fixes P=ofRawRate(D,H), and the same r=P.monotonePrefixRate is antitone, tends to zero, is eventually ≤H, and satisfies (D_pfx⁻¹(t)/t)/r(t)→0. The budget is ⌊tH(t)⌋; a countable diagonal slows D; τ(t)=D_pfx⁻¹(t+1); a natural square-root budget defines the base rate; a tail supremum makes it antitone. ## Algorithm correspondence and separate findings

The main guaranteed Y machine starts with stage 0 and empty output history. At round t it uses Accurate at **stage+1**, emits the earliest unused rank **r>t** in that guess, and advances stage only if stage<t and the updated history crosses threshold(stage+1). It has no candidate list and no strict-rise filter. The paper’s Algorithm 2 uses the current Accurate guess to append strict supersets to G, works through stored candidates, and waits until another candidate exists before advancing. These are materially different named algorithms.

A native printed-style machine is present: `StrictGuessRise`, `appendCurrentGuess`, `gcgRoundCandidates`, `activeGuess` and `gcgStep` (census:572,160,245,126,252). It checks strict rise, stores candidates and advances only with a next candidate and threshold. This is genuine definition coverage, with local freshness/on-time statements. No type equating its gcgOutput with totalizedGCGOutput was found, and the main density/consistency theorem types do not apply to it. An alternate machine can establish the existential phenomenon without establishing Theorem 12 for the printed machine. Its status as an intentional source repair is deferred to Stage 3.

The missing C01/C02/C03 constructions are coverage findings, not claims that a finite inequality or deterministic rate theorem is false. Their probability layers are absent from the supplied interfaces: a scan of all census types found no MeasureTheory/ProbabilityTheory/PMF/expected-value/randomized API, and the inspected targets contain no seed law, expectation, almost-sure event or source-uniform stochastic quantifier. Pathwise or deterministic estimates cannot silently replace these layers.

Representation and construction changes should also remain separate: coding strings by naturals, least target representatives, explicit infinite enumerations, zero ratios at i=0 and deduplicating injective target values are routine qualifications. Independent per-language orders generalize a source assumption. Alternate floors/square-root/tail-envelope profile formulas have matching deterministic semantic estimates. The strict identity-deadline boundary and changed GCG machine are substantive correspondence differences whose intended normalization/repair needs adjudication.
