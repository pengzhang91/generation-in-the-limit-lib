## Standing context and definitions

Sections 3.1–3.2 (pp. 4–7), Appendix A (pp. 29–32), and the discussion (pp. 24–25) supply the common context. The domain X is countable; a hypothesis h is binary, with language supp(h), and every hypothesis has infinite support (UUS). A generator is a deterministic function of an ordered finite input history. It can be computationally unbounded unless an effective oracle algorithm is specifically claimed. Randomized guarantees are outside the framework.

In the element-output setting, a legal replay input x_t is either in the hidden target support or equals an earlier output G(x_1:s), s<t. Eventual success means each later output belongs to the target support and is absent from the entire input prefix. The definition does not separately demand absence from previous outputs. Uniform and non-uniform bounds count **distinct inputs**, including replayed ones; they are not elapsed-round bounds and need no target enumeration. Uniform uses one bound for the whole class; non-uniform allows a bound for each target but not each stream. Limit generation instead requires every target point eventually to appear and permits the success time to depend on both target and stream.

A proper generator returns a member of H each round. Its eventual requirement is containment of the entire output support in the target support, with no requirement that the index stabilize. Proper replay allows any element of any previously output hypothesis support. This permission is stronger than replay of one earlier element output. Membership access means querying h_i(x) for arbitrary listed hypotheses and points, rather than access to the hidden target alone. A subset query compares two whole supports.

## C01 — Theorem 4.1: uniform equivalence

**Locations:** theorem and proof p. 8; Algorithm 1 p. 9; Definitions 3.1–3.2 p. 5 and A.3 p. 30. **Visuals:** [5](visual-checks/page_5.png), [8](visual-checks/page_8.png), [9](visual-checks/page_9.png), [30](visual-checks/page_30.png).

For any UUS binary class over a countable domain, standard and replay uniform generatability are equivalent. Every standard uniform generator with a supplied distinct-input bound d can be converted to a replay generator with no larger bound. Together with the immediate reverse restriction to standard streams, this preserves optimal class sample complexity. H itself need not be countable.

The conversion repeatedly returns the genuine first input until d distinct inputs have appeared, then calls the original generator on the full history. No out-of-target replay is introduced during burn-in; valid later outputs preserve the invariant. This is a semantic black-box transformation with the bound supplied, not an algorithm for finding a class bound or making an arbitrary semantic generator computable. The item includes both directions and the sample-complexity guarantee. Informal references to time must be read using the distinct-input definition.

## C02 — Theorem 5.1: countable non-uniform separation

**Locations:** theorem and proof pp. 9–10; Definition 3.3 p. 5; A.4 p. 30; A.12–A.13 p. 32. **Visuals:** [5](visual-checks/page_5.png), [9](visual-checks/page_9.png), [10](visual-checks/page_10.png), [30](visual-checks/page_30.png), [32](visual-checks/page_32.png).

A countable UUS class is not non-uniformly generatable with replay. The explicit witness on Z has supports N and `{1,…,n} ∪ Z_<0` for positive n. It is non-uniformly generatable in the standard setting by Corollary A.12. The displayed Theorem 5.1 states the replay-negative side; the full separation uses that recalled positive theorem.

If a proposed G succeeds at target N with bound d, present 1,…,d and then replay its latest output forever. The N guarantee forces unboundedly many fresh positive inputs. That same stream is legal for `{1,…,d} ∪ Z_<0`, so its finite target-dependent threshold is eventually reached too. Both guarantees then require a novel output from the finite intersection `{1,…,d}`, which has already been seen. The argument relies on non-uniform streams having no enumeration obligation. It rules out arbitrary deterministic generators, without a query restriction. The standard positive is semantic; A.13 separately excludes a universal membership-only implementation for standard non-uniform generation. This is not a failure of limit generation for countable classes.

## C03 — Theorem 6.1: Witness Protection with membership access

**Locations:** theorem p. 10; access definition and footnote 2 p. 6; definitions p. 11; Algorithm 2 p. 12; Lemmas 6.3–6.5 and final proof pp. 13–14. **Visuals:** [6](visual-checks/page_6.png), [10](visual-checks/page_10.png), [11](visual-checks/page_11.png), [12](visual-checks/page_12.png), [13](visual-checks/page_13.png), [14](visual-checks/page_14.png).

One universal procedure, WP, takes an indexed countable UUS class and generates every target in the limit with replay using only membership queries. Each replay stream must enumerate every target point. The finite success time may depend on both the target and its stream. Crucially, the source also proves that **every round finishes after finitely many operations**, including before stabilization. The result is more than existence of an eventual-validity semantic function.

The algorithm identifies X with the positive integers and uses the supplied hypothesis indexing. It records past outputs O_t and sure inputs S_t, where an arriving input is sure only when it was not an earlier output. Its active finite set contains indices at most t consistent with S_t. A finite-prefix critical candidate has no unsupported points relative to earlier sure-consistent hypotheses except past outputs. WP protects least distinguishing witnesses, then searches increasing prefixes for a point outside S_t, old outputs, and active witnesses.

Lemma 6.3 proves eventual criticality of the true hypothesis: protected target witnesses must eventually arrive genuinely and eliminate finitely many bad earlier candidates. Lemma 6.4 separately proves per-round termination: critical indices decrease only finitely often; after stabilization an infinite support eventually has a point outside the bounded finite forbidden set. Lemma 6.5 proves eventual target validity and novelty. The final theorem explicitly combines finite prefix membership checks, finite per-round completion, and eventual correctness.

The oracle can evaluate any indexed h_i at any point; no whole-support subset oracle is used. The effective result presupposes the indexing/domain enumeration and membership interface. Abstract countability alone does not make membership executable. No uniform runtime or computable stabilization-time bound is stated. One minor wording issue is that the text calls target index z active “for all t,” whereas the active set restricts indices to at most t; the eventual argument concerns t at least z.

## C04 — Theorem 6.6: general-class limit separation

**Locations:** theorem and class p. 15; ordinary positive Lemma 6.7 pp. 15–16; replay-negative Lemma 6.8 and phase-termination Claim 1 pp. 16–17; limit definitions pp. 6 and 30. **Visuals:** [6](visual-checks/page_6.png), [15](visual-checks/page_15.png), [16](visual-checks/page_16.png), [17](visual-checks/page_17.png), [30](visual-checks/page_30.png).

A UUS class over a countable domain is generatable in the limit ordinarily but fails with replay. The construction is uncountable, although the theorem sentence does not repeat that adjective. Its domain is Z disjointly joined with markers `star_k`, k≥1. For each b≥0, one integer family contains b and a full sufficiently high tail, with arbitrary other integer membership; a second contains every integer below b, omits b, and has arbitrary other membership. Both are padded with exactly the first b markers. The class also contains the all-marker hypothesis.

For ordinary inputs, a generator uses the greatest observed marker index m, defaulting to 0, to select an integer generator. That routine moves upwards once b is seen and downwards otherwise. Marker-only histories receive a fresh marker. On any complete target enumeration the marker index stabilizes, and the relevant integer routine eventually succeeds. This explicit positive generator uses history operations without membership queries, even though arbitrary members of the class need not have computable membership.

For the negative side, a hypothetical replay-successful G is first forced to output a new large marker `star_z`. After presenting the markers through z, phase n presents z−n and an increasing high tail until G emits a fresh high integer. That output becomes a cutoff never presented in later phases. Claim 1 is essential: if a phase never finished, the stream would enumerate an alternative padded target with first z−1 markers and a full upper tail, except for the single `star_z` already justified as a previous output. Replay-success would then force the phase to finish. All phases therefore finish; the final actually presented support belongs to the second family with z markers, while infinitely many forbidden cutoff outputs fall outside it.

The phase-termination claim concerns the adversarial construction, not a computational runtime theorem for arbitrary generators. The single potentially out-of-target replay occurs in the alternative-target argument; it must not be confused with the final target chosen after all phases. Footnote 7 explains why the unpadded family alone does not separate replay: protecting b suffices there. For b=0 the proof's maximum target-marker index implicitly needs the same empty-marker convention that is explicit for m(t).

## C05 — Theorem 7.1 and Lemma 7.2: proper membership lower bound

**Locations:** theorem and interface p. 18; Algorithm 3 p. 19; Lemma 7.2 pp. 20 and 22; theorem proof pp. 22–23; proper definitions p. 31; membership-plus-subset comparison A.15 p. 32; subset access footnote p. 7. **Visuals:** [7](visual-checks/page_7.png), [18](visual-checks/page_18.png), [19](visual-checks/page_19.png), [20](visual-checks/page_20.png), [22](visual-checks/page_22.png), [23](visual-checks/page_23.png), [31](visual-checks/page_31.png), [32](visual-checks/page_32.png).

This slot has distinct computational components. Theorem 7.1 excludes one deterministic membership-only algorithm that properly generates in the limit **every** countable UUS class, already without replay. Its surrounding proof concerns computable oracle algorithms returning hypothesis indices. Algorithm 3 constructs a hard indexed class depending on the proposed algorithm. Lemma 7.2 separately asserts that its membership function F(i,j) is total recursive and that each support `{j:F(i,j)=1}` is infinite. Both parts of the lemma belong to the source scope.

The construction makes permanent decisions for entire membership columns, maintains bounds I,J on explored indices and instances, and uses a minimum-first queue to enumerate a target. A nonreference output receives a fresh diagonal point unique to its support; the current trap is released into the queue and a new trap is installed at a fresh index. Common points are added at the end of every completing round. If the algorithm produces nonreference outputs infinitely often, the queue enumerates the reference support and diagonal points yield infinitely many inclusion errors. If only finitely often, it eventually returns the reference hypothesis while the queue enumerates the final trap hypothesis, which omits a point of that reference support. Every queued value eventually appears.

The construction's effectiveness is not assumed away by eventual correctness. Lemma 7.2 proves J tends to infinity either through completing rounds or through infinitely many queries within one round, using a query counter k with J≥k. Every membership entry is thus fixed at a finite construction step; the same two cases provide infinitely many common supported points. A claimed successful proper generator must actually halt with an index every round. The source explicitly handles infinite querying; it does not separately analyze arbitrary partial programs silently diverging internally after finitely many queries, so the inventory retains its computable-generator protocol.

This is a universal-algorithm lower bound with a candidate-dependent effective hard class. It does not claim that one fixed class lacks every semantic proper generator. Indeed A.15 recalls proper generation for all countable classes with membership and subset access. Proper success is eventual support containment, not exact identification or index stabilization. No query or convergence-time bound is supplied.

## C06 — Theorem 7.3: four-language proper separation

**Locations:** theorem and four supports p. 23; proof pp. 23–24; Definition 3.5 p. 7; A.6–A.7 p. 31 and A.15 p. 32. **Visuals:** [7](visual-checks/page_7.png), [23](visual-checks/page_23.png), [24](visual-checks/page_24.png), [31](visual-checks/page_31.png), [32](visual-checks/page_32.png).

A finite UUS class is not properly generatable in the limit with replay. The explicit class has four supports on Z: `Z_≤0 ∪ {i}` and `Z_≥0 ∪ {−i}`, for i=1,2. The displayed theorem asserts the negative side; ordinary proper generation follows from the recalled countable-class positive A.15 and supplies the contextual separation. Four is the exhibited size; no minimality assertion appears.

Start with 0. If G first outputs the negative-half-line language with extra point 1, present −1, −2, then every positive integer. Those two negative points are permitted replays from the support of that first output. The same stream is a full proper replay enumeration for both positive-half-line targets. Success for both would eventually force an output support into their intersection `Z_≥0`, but none of the four hypotheses fits. The other first choices follow by sign/index symmetry.

This rules out unrestricted deterministic proper generators, without a query or runtime restriction. The permission to replay any member of a prior output **support** is essential; replacing it by replay of one prior element output changes the model. The item has no independent effective-computation or per-round search claim.
