Since every empirical noise rate is at most one, Condition 3 at c=1 reduces to: every nonempty finite subcollection has intersection lower density at least ρ in each member. Each such core is therefore infinite.

For necessity, any finite subfamily admits a shared injective enumeration of its union. The union is countably infinite; that enumeration contains every selected target, so it has infinite overlap and no omissions for all members, and automatically satisfies noise ≤1 at every prefix. A uniform successful generator eventually lies inside every selected language, hence inside their core. Its lower density cannot exceed the core's lower density in any selected target. Thus the assumed density guarantee forces Condition 3, including with the formal infinite-overlap convention.

For sufficiency, output the intersection of the first n family members minus the observed sample. These sets are infinite at every round; the empty initial prefix may use the whole universe. Once n includes target index z, the output lies in that target, and Condition 3 gives density ≥ρ at every such round. Finite deletion preserves this density. No informative observations are needed, and the same generator works even on streams with no valid observations. It consequently works on the narrower source admissible streams. This is causal and uses only the known family, not the unknown target.

The missing step in the printed interior proof does not make an extra data premise necessary. ## Residue, rank, and equality checks

### The displayed witnesses and a finite-marker repair

Example 5.5 (p.29/PDF32) prints single residue classes and claims noise 1/k. Their noise is normally `1−1/k`; the printed i=k remainder class is empty under ordinary remainders, and k=1 cannot witness failure with one infinite language. Example 7.2 (p.50/PDF53) prints `L_i=[k]∪(N\iN)`. Its i=1 language is finite; for general i its limiting noise is 1/i, not uniformly 1/k. These fail actual premises, not merely labels.

Here is a repaired family preserving the intended critical noise conclusion for k≥2. On positive naturals let `F={1,…,k}` and

`L_r = F ∪ {m≥1 : m mod k ≠ r}`, for `r=0,…,k−1`, with `x_n=n`.

All k languages are infinite and distinct, every target is completely enumerated, and their common intersection is exactly finite F. For n<k every noise count is zero. Write n=qk+s≥k with 0≤s<k. The bad count is q for residues 1,…,s and q−1 for the other residues, including zero. Thus every bad count is at most n/k at **every prefix**. No limit approximation is needed. The corresponding zero-based version uses F={0,…,k−1}, prefix values 0,…,n−1, and the q case on residues r<s; it gives the identical bound.

A successful uniform generator must eventually output inside F on this common stream. But F is already observed after k rounds, contradicting novelty. This proves the intended existential critical-noise obstruction informally. It repairs Example 5.5 by changing the family, index range, and k range; it does not vindicate its literal formula.

### Theorem 7.7's literal factor is impossible

Unlike B.3, the printed `M=1/k, c=1/k` statement (p.52/PDF55) has an intrinsic feasibility problem. Source rank is **one-based**: the j-th canonical target element has rank j, not j−1. Displacement is an eventual exact bound `rank(x_t)≤M t`. Let N0 be its threshold. All finitely many valid observations before N0 have fixed finite ranks; since M>0, choose N1 so the growing window floor(Mn) contains every one of them for all n≥N1. For later observations t≤n, their ranks are ≤Mt≤Mn. Thus, eventually, **all** valid values in the first n observations lie among the first floor(Mn) target elements. Injectivity gives the exact bound

`validCount(n) ≤ floor(Mn)`.

There is no additive constant after this catch-up. Exact eventual noise ≤c gives `validCount(n)≥ceil((1−c)n)`. With M=c=1/k, k>2 contradicts linear growth; k=2 contradicts every sufficiently large odd n because ceil(n/2)>floor(n/2). Native rank on its carrier is `canonicalIndex+1`, and its input index j uses M(j+1); a prefix of length n ends at j=n−1, yielding the same M n window. Both source and native predicates are eventual inequalities, not limsup bounds.

Hence no admissible stream exists for these parameters for **any** k≥2. Universal success over that stream class is vacuous, so the literal existential non-generability claim is false under the stated model. A factor below one is not inherently impossible under all noisy models; the contradiction uses these particular exact noise/rank constraints.

For the repaired marker family above, canonical x_n=n is 1-bounded relative to every L_r because a member's target rank is at most n. It is therefore also `(1+1/k)`-bounded, with exact critical noise and finite core. This supports a corrected existential theorem with that larger factor, but the documentation's factor-only repair leaves Example 7.2's family defects unfixed. No corrected native theorem exists.
