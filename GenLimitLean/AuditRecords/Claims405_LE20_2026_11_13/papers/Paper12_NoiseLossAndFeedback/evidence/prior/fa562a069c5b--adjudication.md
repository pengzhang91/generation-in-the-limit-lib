Append a bijective enumeration of `K \ range(h)`. The concatenation is injective, retains every prefix position, covers `K`, and adds only the finitely many prefix nonmembers. ### Finite feedback: literal predicates versus preserved class guarantees

Definition 6.5, p.18, literally quantifies any infinite input/answer sequence; its surrounding protocol fixes bottom answers exactly on abstention rounds. Native `CompatibleResponses:78` enforces that pattern but permits either Boolean bit on a real query. `HasAtMostQueries:88` bounds every such history, not just truthful target runs. The documented legal-history reading is therefore justified by the surrounding source context, but cannot erase the literal stronger reading.

The predicates are not identical for each controller. Over naturals, consider a controller that abstains unless some previous answer is `some`; after such an answer it queries `0` forever. Every compatible execution has only `none` answers and no queries, satisfying budget zero. A malformed `some false` after an initial abstention causes infinitely many later queries. This is an informal counterexample to literal fixed-controller predicate equivalence.

Class-level guarantees survive a causal normalization. Given a controller `G` capped on compatible histories, recursively normalize each past raw answer using the query that `G` asks on the already normalized past: replace it by `none` if that query abstains, otherwise by `some(raw.getD false)`. The normalized controller asks `G`'s query and outputs `G`'s output on these normalized histories, including the current normalized answer. Every arbitrary raw execution now induces a compatible execution of `G`, with exactly the same query stages, so its global cap holds even on malformed raw histories. On truthful legal executions, induction gives the original transcript, queries, outputs, and thresholds unchanged. The reverse class inclusion is immediate by restriction. No additional target query, oracle, noncausal input, or selection principle is introduced; a finite recursive wrapper also preserves any pre-existing computational implementation. It does not create an effective base learner.

This normalization argument is M only; no normalization declaration was identified or added. Thus the class-level interpretation of 1.7 is supported, while literal equality of the two fixed-controller predicates remains false.

The finite-feedback elimination repair is independently sound: the actual truthful query set is finite; completeness eventually reveals every positively answered queried value.
