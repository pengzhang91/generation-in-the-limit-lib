## 2. Mathematical setting and notation

The fixed-universe layer uses natural numbers both as example values and as indices of languages. Let

* `C : ℕ → Set ℕ` be an indexed family, and write `C_i := C i`;
* `x : ℕ → ℕ` be a stream, with `x_t := x t`;
* `S_t := {x_s : s<t}` be the finite set of distinct observations strictly before time `t`;
* `[0,m) := {u∈ℕ : u<m}` be the strict natural-number cutoff prefix.

Exact presentation is `range(x)=L`. Consistency of index `i` at time `t` is `S_t⊆C_i`. This is positive-data consistency: only observed values are constrained. Repeated observations are permitted because presentation and samples use set range/image. The main oracle-family interface additionally requires every `C_i` to be infinite and supplies a Boolean membership function exact for every pair `(i,u)`.

The generic layer replaces the example universe `ℕ` by an arbitrary type `α : Type u`, but it retains natural time. A finite history of length `t` is a function `Fin t → α`; a generic generator returns an `α` after receiving `t` and such a history. Despite the source file’s label, the visible signatures impose no countability assumption on `α`.

Four concrete output rules are visible in the declarations:

1. a noncomputable round-indexed semantic rule using maximal whole-language criticality;
2. a noncomputable finite-observed-set semantic rule whose candidate scope is `S.card`;
3. a finite-prefix oracle rule that stops when the newly reached endpoint `q−1` is in the currently selected language;
4. a finite-prefix oracle rule that stops when any fresh selected-language element exists below `q` and returns the least such element.

This enumeration follows the right-hand sides of the definitions. It is not an attribution of motivation or historical intent.

## 3. Primitive objects and access model

### 3.1 Fixed indexed sets and exact presentations

A language is just a set. A family is an arbitrary natural-indexed function and therefore can repeat the same set at multiple indices. An exact presentation is a total stream whose range equals the target. Nothing in the relation records a discovery rate, an index for first occurrence, or an order constraint.

### 3.2 Two oracle records

`GenLimit.MembershipOracle C` supplies only exact Boolean membership for a fixed family `C`. `GenLimit.OracleFamily` packages a family, infinitude of every member, and exact Boolean membership. The latter is the interface consumed by all four concrete output rules. Neither record states a time/query complexity, continuity property, enumeration procedure, or injectivity of the family index.

### 3.3 Information visible to the output rules

The round-indexed whole-set-inclusion rule is written as a function of `O`, the full stream object, and `t`, but its transitive definitions inspect the stream through `S_t`; it also inspects whole-language inclusion and uses the infinitude fields. The finite-set rule takes `O` and a finset `S` literally. The two stateful finite-prefix rules recursively inspect prior observations and Boolean membership values on finite prefixes, then use unbounded least cutoffs whose existence is supplied by theorem signatures. None receives the target index `z` as an input. The target index appears only in correctness specifications and can affect the existential convergence threshold. This is a statement-level access description, not a black-box complexity claim: `OracleFamily` also exposes the full family and infinitude fields, and no opacity theorem or query-cost model appears.

### 3.4 Freshness

Every final correctness predicate requires the current generated value to be absent from the observed sample `S_t`. No definition or theorem statement requires generated outputs to be mutually distinct, or to avoid outputs produced at earlier rounds unless those outputs also occurred in the input stream.

### 5.1 Common literal content of the seven main declarations

The seven declarations comprise five distinct normalized propositions because two pairs are statement-identical. Across them, a family object is fixed before the target is chosen. Given any target index `z` and any exact presentation of that indexed language, the relevant eventual-correctness conclusion is

`∃ T, ∀ t, T ≤ t → output(t) ∈ C_z ∧ output(t) ∉ S_t`.

The threshold occurs after `O`, `stream`, `z`, and the presentation hypothesis and may therefore depend on them. The output function itself does not receive `z`. The statements are eventual and pointwise in time; they do not state a uniform threshold over all targets or presentations, an explicit rate, a density guarantee, or pairwise distinctness of outputs.

### 8.1 Empty and zero cases

* `sample stream 0` and `finitePrefix i 0` are empty by their right-hand sides.
* `FinitelyCritical … m=0 …` retains consistency but its element-comparison clause is vacuous.
* Both semantic `focus` definitions return `0` when their critical-index finset is empty.
* Both machine states start at `(counter,output)=(0,0)`; if a round has no consistent candidate, `processRound` returns `(b,0)` and gives no correctness guarantee for that output.
* Endpoint `Stop` is defined for arbitrary `q` using truncated subtraction `q−1`; found round counters are separately specified to exceed the nonnegative start and hence are positive.
* Finite-scope theorems at scope `s=0` have vacuous inner candidate quantification. Target-prefix theorems at `z=0` still quantify over index `0` where the bound is `i≤z`.
* If the generic example type `α` is empty, there is no inhabitant of `Stream α = ℕ → α`; there is also no inhabitant of `Generator α`, because its `t=0` component must return an `α` from the unique empty history. Generic theorem signatures do not exclude this degenerate type explicitly.
* An exact presentation by a total natural-time stream necessarily has nonempty range; the relation itself does not separately state nonemptiness. `OracleFamily` targets are in any event infinite.

### 9.1 Final-statement expansion by rule

For the endpoint finite-prefix, query-relative main statement, the generated value at time `t` is the `output` field of a recursive state. At a successful round its value is `q−1`, where `q` is the least cutoff above the raised start for which the endpoint belongs, according to `query`, to the maximum finite-critical candidate below `t`.

For the first-fresh-eligible main statement, the generated value is the least sample-unseen member below the first successful cutoff of the maximum finite-critical candidate at that cutoff. Counter and output are separate fields.

For the round-indexed semantic main statement, the generated value is the least sample-unseen member of the maximum whole-language-critical index below `t`, with a default focus of `0` when the critical set is empty.

For the finite-set main statements, elapsed time is absent from the generator input. The candidate scope is the cardinality of the observed finset, and the output is the least element outside that finset of the maximally set-critical language in that scope.
