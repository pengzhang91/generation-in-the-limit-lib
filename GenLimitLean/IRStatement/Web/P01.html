How to read the IR statements
  • “Let …” introduces an object, and “Suppose that …” adds an assumption. Both stay in force to the end of the text, or of the bullet they are in.
  • “There is T ∈ ℕ, depending only on …, with the following property.” chooses T, and the rest of the text is the property; when the property is a list, it reads “with the following properties:”. Lean checks the list of dependencies. The list is shown only when the property opens with a new variable (“Let …” or “for every …”), so that the reader sees that T does not depend on it. Otherwise T may depend on everything above, and the list is left out.
  • “All of the following hold:”, “The following are equivalent:” and “At least one of the following holds:” are followed by bullets.
  • A word in italics is the label of a Lean constant, made from its name; point at it to see the constant. A label with one argument reads “X is label”, otherwise label(X, Y, …) with Lean's argument order. Some labels read as a short sentence instead, such as “𝒢 achieves time vector t on 𝒞”; the label's definition in the glossary uses the same sentence. Its negation reads “X is not label …” when the sentence has “is”, and again takes no quantifier after it.
  • “Let K = …” names a term that occurs several times. (x, y) is a pair, [x, y] a list, and () the only element of the one-point type. {0, …, k − 1} is Lean's Fin k. ⟨x⟩ is x as an element of a subtype, such as C(z) in the range of C; Lean supplies the proof of membership. “A member of S” is an element of the set S as a type, and “the set F” is a finite set F used as a set.
  • “Let t ≥ T.”, “for every t ≥ T”, “for every i < n” and “there is i < n such that” range over natural numbers.
  • A proof passed to a label is not shown when Lean can prove it from the assumptions. “label(X, Y) does not hold” and A ⊈ B are negations; no quantifier follows “does not hold”. Many names follow the paper (𝒞, ℋ, t⋆, …), to make reading the two side by side easier; each statement still says what its names stand for.
  • A statement that begins with “Setting A.” begins with the sentences of Setting A, listed under “Throughout”. The checker puts them in place of the mark.
  • A label with a dotted underline links to its definition in the glossary at the end of the page. A definition reads “By definition, … if and only if …”; Lean proves it by Iff.rfl, so it is the label's definition, unfolded once.
  • {x(n) : n < t} is the set of the first t terms of x, and ∖ is set difference. “O has a membership oracle” means that O comes with a correct test for x ∈ Li.

The paper’s setting (3)

  • we have a countable list of candidate languages C = {L1, L2, L3, . . .}, where each Li is a subset of some countable set U. All we assume about the list of languages is that it is specified through a black box that can answer questions of the form “Is w ∈ Li?” for any string w ∈ U and language Li ∈ C.

    p. 3

  • We will assume that all the languages Li are infinite

    p. 3

  • The adversary chooses a language K from C without revealing it to the algorithm, and it begins enumerating the strings of K one by one over a sequence of steps t = 1, 2, 3, . . .. The adversary can repeat strings in its enumeration, but crucially, for every string w ∈ K, there must be at least one time step t in which w appears. Let St be the set of strings that the adversary has enumerated in steps 1 through t.

    p. 3

Theorem 2.1 Countable-family generation in the limit

In the paper (2.1), p. 4

There is an algorithm with the property that for any countable collection of languages C = {L1, L2, L3, . . .}, and any enumeration of one of these languages K, the algorithm generates from K in the limit.

Terms from the paper (1)

  • In each step, the algorithm observes St and must output a string at (its guess for an unseen string in K). The algorithm generates from K in the limit if there is some t∗ such that for all steps t ≥ t∗, the algorithm’s guess at belongs to K − St.

    p. 4

IR statement checked by Lean

Let C be an indexed family of languages L0, L1, L2, … ⊆ ℕ. Each Li is infinite. C has a membership oracle. Let G be the membership-query generator for C. Let x be a sequence of natural numbers. Let o(t) be the output of G on x at step t. Let z ∈ ℕ.

Suppose that the set of values of x is exactly Lz.

Then there is t⋆ ∈ ℕ, depending only on C, x and z, with the following property. For every t ≥ t⋆, o(t) ∈ Lz ∖ {x(n) : n < t}.

Theorem 2.2 Uniform finite-family generation

In the paper (2.2), p. 4

There is an algorithm with the property that for any finite collection of languages C, there is a number t(C), such that for any language K in C, and any sequence S of at least t(C) distinct elements from K, the algorithm can produce an infinite sequence of distinct strings from K − S.

IR statement checked by Lean

Let O be an indexed family of languages L0, L1, L2, … ⊆ ℕ. Each Li is infinite. O has a membership oracle. Let C be a finite set of natural numbers.

There is tC ∈ ℕ, depending only on O and C, with the following property.

Let S be a finite set of natural numbers with |S| ≥ tC. Let I = {i ∈ C : the oracle confirms x ∈ Li for every x ∈ S}. Let A = {x ∈ ℕ ∖ S : the oracle confirms x ∈ Li for every i ∈ I}. Let z ∈ C with S ⊆ Lz.

Then A is infinite. Let u list the elements of A in increasing order. Then u is injective and every value of u lies in Lz ∖ S.

Theorem 7.1 Robust-prompt generation

In the paper (7.1), p. 10

There is an algorithm with the property that for any countable collection of languages C = {L1, L2, L3, . . .}, and any enumeration of one of these languages K accompanied by a sequence of robust prompts, the algorithm achieves prompted generation from K in the limit.

Terms from the paper (3)

  • in every step t, the adversary provides the algorithm with two things: a string wt from the true language K, and a string pt that serves as a prompt.

    p. 9

  • We say a prompt p is robust if for all languages Li ∈ C, there exist arbitrarily long strings c for which p · c ∈ Li.

    p. 9

  • We say that the algorithm achieves prompted generation from K in the limit if there is some t∗ such that for all steps t ≥ t∗, the algorithm’s output at has the property that pt is a prefix of at and at ∈ K − St.

    p. 10

IR statement checked by Lean

Let A be a type. Assume that equality on A is decidable. Let e be a bijection from words over A to ℕ. Let C be an indexed family of languages L0, L1, L2, … of words over A. Each Li is infinite. C has a membership oracle. Call a word over A robust if it has arbitrarily long extensions in every Li. Let G be the prompted membership-query generator for C with coding e. Let x be a sequence of words over A. Let z ∈ ℕ.

Suppose that the set of values of x is exactly Lz.

Let p be a sequence of words over A.

Suppose that p(t) is robust for every t ∈ ℕ.

Let w(t) be the output of G on x and p at step t.

There is t⋆ ∈ ℕ, depending only on A, e, C, x, z and p, with the following property. For every t ≥ t⋆, p(t) is a prefix of w(t) and w(t) ∈ Lz ∖ {x(n) : n < t}.
