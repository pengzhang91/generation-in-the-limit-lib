## Theorem 2.1

Let C be an indexed family of languages L_0, L_1, L_2, … ⊆ ℕ. Each L_i is infinite. C has a membership oracle. Let G be the membership-query generator for C. Let x be a sequence of natural numbers. Let o(t) be the output of G on x at step t. Let z ∈ ℕ.

Suppose that the set of values of x is exactly L_z.

Then there is t⋆ ∈ ℕ, depending only on C, x and z, with the following property. For every t ≥ t⋆, o(t) ∈ L_z ∖ {x(n) : n < t}.

## Theorem 2.2

Let O be an indexed family of languages L_0, L_1, L_2, … ⊆ ℕ. Each L_i is infinite. O has a membership oracle. Let C be a finite set of natural numbers.

There is t_C ∈ ℕ, depending only on O and C, with the following property.

Let S be a finite set of natural numbers with |S| ≥ t_C. Let I = {i ∈ C : the oracle confirms x ∈ L_i for every x ∈ S}. Let A = {x ∈ ℕ ∖ S : the oracle confirms x ∈ L_i for every i ∈ I}. Let z ∈ C with S ⊆ L_z.

Then A is infinite. Let u list the elements of A in increasing order. Then u is injective and every value of u lies in L_z ∖ S.

## Theorem 7.1

Let A be a type. Assume that equality on A is decidable. Let e be a bijection from words over A to ℕ. Let C be an indexed family of languages L_0, L_1, L_2, … of words over A. Each L_i is infinite. C has a membership oracle. Call a word over A robust if it has arbitrarily long extensions in every L_i. Let G be the prompted membership-query generator for C with coding e. Let x be a sequence of words over A. Let z ∈ ℕ.

Suppose that the set of values of x is exactly L_z.

Let p be a sequence of words over A.

Suppose that p(t) is robust for every t ∈ ℕ.

Let w(t) be the output of G on x and p at step t.

There is t⋆ ∈ ℕ, depending only on A, e, C, x, z and p, with the following property. For every t ≥ t⋆, p(t) is a prefix of w(t) and w(t) ∈ L_z ∖ {x(n) : n < t}.
