## *compatible*

Let O be a sequence of *ordered languages*.

By definition, O is *compatible* if and only if the following holds.

Let i, j, a, b, c and d be natural numbers.

Suppose that *enumeration*(O(i), a) = *enumeration*(O(j), c). Suppose that *enumeration*(O(i), b) = *enumeration*(O(j), d). Suppose that a < b.

Then c < d.

## *element valid*

Let s and g be sequences of natural numbers. Let K be a *language*.

By definition, g is *element valid* on s for K if and only if the following holds.

There is T ∈ ℕ, depending only on s, g and K, with the following property.

Let t ∈ ℕ.

Suppose that t ≥ T.

All of the following hold:
- g(t) ∈ K.
- Let i ∈ ℕ with i ≤ t. Then s(i) ≠ g(t).
- g(i) ≠ g(t) for every i < t.
