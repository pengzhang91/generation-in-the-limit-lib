## *is MSM choice*

Let Candidate and Config be types. Assume that equality on Candidate is decidable. Let candidates be a function from Config to finite sets of elements of Candidate. Let score be a function from Config to (Candidate → ℕ). Let config be an element of Config. Let choice be an element of Candidate.

By definition, choice *is MSM choice* at config among candidates by score if and only if the following holds.

All of the following hold:
- choice ∈ candidates(config).
- 0 < score(config, choice).
- score(config, other) ≤ score(config, choice) for every other ∈ candidates(config).
