## *condition five*

Let F be an *effective indexed family*.

By definition, F is *condition five* if and only if the following holds.

There is a *p fun* select over (Finset ℕ) and ℕ with the following properties:
- (h ↦ select(*to finset*(h))) is *partrec*.
- Let S be a finite set of natural numbers. Suppose that S is *finset nonempty*. Suppose that there is j ∈ ℕ such that *descriptive*(F, S, j). Then there is j ∈ select(S) such that *descriptive*(F, S, j).

## *condition four*

Let F be an *effective indexed family*.

By definition, F is *condition four* if and only if the following holds.

There is a sequence inclusion of sequences of Booleans with the following properties:
- inclusion is *computable₂*.
- Let i and j be natural numbers. Then inclusion(i, j) = *true* if and only if *language*(F, i) ⊆ *language*(F, j).

## *condition three*

Let C be a *language family* over ℕ.

By definition, C is *condition three* if and only if the following holds.

Let S be a finite set of natural numbers.

Suppose that S is *finset nonempty*.

Then {L ⊆ ℕ : L ∈ *range*(C) and S ⊆ L} is *finite*.

[Lean definition](../../../GenLimit/Paper00A_PositiveDataInference/Effective/Definitions.lean#L53) · `GenLimit.Angluin.ConditionThree`

## *conservative*

Let M be an *inference machine*. Let F be an *effective indexed family*.

By definition, M is *conservative* on F if and only if the following holds.

Let i ∈ ℕ. Let s be a *stream* over ℕ.

Suppose that *presents*(s, *language*(F, i)).

Let n, k, j, m, l and g be natural numbers.

Suppose that *earlier*(n, k, m, l). Suppose that *guesses*(M, s, n, k, j). Suppose that *guesses*(M, s, m, l, g). Suppose that g ≠ j.

Then there is t < m such that s(t) ∉ *language*(F, j).

[Lean definition](../../../GenLimit/Paper00A_PositiveDataInference/Effective/InferenceMachine.lean#L43) · `GenLimit.Angluin.InferenceMachine.Conservative`

## *consistent*

By definition, M is *consistent* on F if and only if the following holds.

## *effective inferrable*

Let F be an *effective indexed family*.

By definition, F is *effective inferrable* if and only if the following holds.

There is an *effective identifier* M such that M is *computable* and M *semantically identifies* *language*(F).

## *identifies*

Let M be an *inference machine*. Let F be an *effective indexed family*.

By definition, M *identifies* F if and only if the following holds.

Let i ∈ ℕ. Let s be a *stream* over ℕ.

Suppose that *presents*(s, *language*(F, i)).

Then there are n ∈ ℕ, k ∈ ℕ and j ∈ ℕ with the following properties:
- *guesses*(M, s, n, k, j).
- *language*(F, j) = *language*(F, i).
- Let m, l and g be natural numbers. Suppose that *earlier*(n, k, m, l). Suppose that *guesses*(M, s, m, l, g). Then g = j.
