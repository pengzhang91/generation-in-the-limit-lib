## *error*

Let α be a type. Let k ∈ ℕ. Let F be a *language family* over α. Let A be a *kernel* over α and k. Let p be a *PMF* over α. Let K be a *language* over α. Let n ∈ ℕ.

By definition, *error*(F, A, p, K, n) = *probability*(*bind*(*samples*(p, n), A), *misses*(F, K)).

## *exponential*

Let α be a type. Let k ∈ ℕ. Let F be a *language family* over α. Let A be a *kernel* over α and k.

By definition, A identifies F at *exponential* rate if and only if the following holds.

Let i ∈ ℕ. Let p be a *PMF* over α.

Suppose that *support*(p) = F(i).

Then there is c ∈ ℝ with the following properties:
- c > 0.
- There is D ∈ ℝ with the following properties:
  - D > 0.
  - *error*(F, A, p, F(i), n) ≤ D · *exp*(−c · ↑n) for every n ∈ ℕ.

## *has angluin stratification*

Let α be a type. Let F be a *language family* over α. Let k ∈ ℕ.

By definition, F *has angluin stratification* with k layers if and only if the following holds.

There is a list layers of subsets of ℕ with the following properties:
- *length*(layers) = k.
- layers *covers all indices*.
- *relative condition two*(F, I) for every I ∈ layers.

## *infinite draws identifies*

Let α be a type. Assume that α is *measurable space*. Let F be a *language family* over α. Let k ∈ ℕ. Let p ∈ ℝ.

By definition, *infinite draws identifies* F with list size k with probability at least p if and only if the following holds.

There is a *list identifier* D over α and k, depending only on α, F, k and p, with the following property.

Let z ∈ ℕ. Let q be a *PMF* over α.

Suppose that *support*(q) = F(z).

Then p ≤ *real*(*iid*(*to measure*(q)), *success*(F, D, z)).

## *nontrivial for*

Let α be a type. Let F be a *language family* over α. Let k ∈ ℕ.

By definition, F is *nontrivial for* k if and only if the following holds.

There are a finite set S of *languages* over α and an element x of α with the following properties:
- *card*(S) = k + 1.
- Let K ∈ S. Then K ∈ *range*(F) and x ∈ K.

## *probabilistic identifies*

Let α be a type. Let F be a *language family* over α. Let k ∈ ℕ. Let p ∈ ℝ.

By definition, *probabilistic identifies* F with list size k with probability at least p if and only if the following holds.

There is an *identifier* A over α and k, depending only on α, F, k and p, with the following property.

Let z ∈ ℕ. Let s be a *stream* over α.

Suppose that *presents*(s, F(z)).

Then p ≤ *real*(*fair*, *stable event*(F, A, s, z)).
