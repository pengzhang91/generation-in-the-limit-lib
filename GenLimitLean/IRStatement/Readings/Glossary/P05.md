## *achieves scaled approximate breadth rate*

Let C be a *language family* over ℕ. Let G be a *statistical generator*. Let R be a function from ℝ to ℝ.

By definition, G *achieves scaled approximate breadth rate* R for C if and only if the following holds.

Let i ∈ ℕ. Let p be a *PMF* over ℕ.

Then there is c ∈ ℝ with the following properties:
- 0 < c.
- There is D ∈ ℝ with the following properties:
  - 0 < D.
  - *approximate breadth error*(C, G, p, i, n) ≤ D · R(c · ↑n) for every n ∈ ℕ.
