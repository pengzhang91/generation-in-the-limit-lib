## *exhaustively generatable*

Let α be a type. Let C be a *language class* over α.

By definition, C is *exhaustively generatable* if and only if the following holds.

There is an *exhaustive algorithm* A over α such that *is exhaustive generator*(A, C).

## *has finite GF dimension*

Let α be a type. Let C be a *language class* over α.

By definition, C *has finite GF dimension* if and only if the following holds.

There is d ∈ ℕ such that *GF dimension at least*(C, d) does not hold.

## *weak angluin existence*

Let α be a type. Let C be a *language class* over α.

By definition, C is *weak angluin existence* if and only if the following holds.

Let L ∈ C.

There is a finite set T of elements of α with the following properties:
- T ⊆ L.
- Let L' ∈ C with T ⊆ L'. Suppose that *s subset*(L', L). Then L ∖ L' is *finite*.
