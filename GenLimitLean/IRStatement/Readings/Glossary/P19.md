## *finite noisy closure dimension at*

Let α be a type. Let C be a *language class* over α. Let i ∈ ℕ.

By definition, C has *finite noisy closure dimension at* noise level i if and only if the following holds.

There is D ∈ ℕ, depending only on α, C and i, with the following property.

Let d ∈ ℕ.

Suppose that D < d.

Then *noisy closure witness at*(C, i, d) does not hold.

## *has finite dimension exhaustion at*

Let α be a type. Let C be a *language class* over α. Let i ∈ ℕ.

By definition, C *has finite dimension exhaustion at* noise level i if and only if the following holds.

There is a sequence layers of *language classes* over α with the following properties:
- layers is *monotone*.
- C = *i union*((j ↦ layers(j))).
- layers(j) has *finite noisy closure dimension at* noise level i for every j ∈ ℕ.

[Lean definition](../../../GenLimit/Paper19_EffectOfNoise/Nonuniform.lean#L29) · `GenLimit.QuantifyingNoise.HasFiniteDimensionExhaustionAt`
