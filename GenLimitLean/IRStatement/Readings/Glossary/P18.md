## *safely generates*

By definition, G *safely generates* from target given harmful on x if and only if the following holds.

All of the following hold:
- Suppose that target ∖ harmful is *infinite*. Then there is T ∈ ℕ, depending only on α, G, target, harmful and x, with the following property. For every t ≥ T, *safe correct at*(G, target, harmful, x, t).
