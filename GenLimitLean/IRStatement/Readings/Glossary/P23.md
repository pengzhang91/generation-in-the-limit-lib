## *admissible box*

Let d ∈ ℕ. Let f be a sequence of real numbers. Let P be a set of *lattices* over d. Let n ∈ ℕ. Let r be a pair in *lattice*(d) × *lattice*(d).

By definition, r is an *admissible box* for P at threshold n under f if and only if the following holds.

Let V = *geometric volume*(*fst*(r), *snd*(r)).

All of the following hold:
- *fst*(r, j) < *snd*(r, j) for every j ∈ {0, …, d − 1}.
- 2 ≤ V.
- 0 < f(V).
- ↑n ≤ ↑*card*(*box*(P, *fst*(r), *snd*(r))) / (f(V) · *log*(↑V)).

## *cube valid*

By definition, A is *cube valid* on s for K if and only if the following holds.

- *cube play*(A, s, i) ≠ M for every i < t.
