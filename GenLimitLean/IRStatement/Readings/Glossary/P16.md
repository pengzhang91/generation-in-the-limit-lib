## *DFA at most*

Let s ∈ ℕ. Let L be a set of lists of Booleans.

By definition, L has *DFA at most* s states if and only if the following holds.

There is q ∈ ℕ with the following properties:
- q ≤ s.
- There is a *DFA* M over Bool and {0, …, q − 1} such that *DFA accepts*(M) = L.

[Lean definition](../../../GenLimit/Paper16_ComplexityBarriers/BlockDFA.lean#L15) · `GenLimit.ComplexityBarriers.Blocks.DFAAtMost`

## *LTT at most*

Let α be a type. Let s ∈ ℕ. Let L be a set of words over α.

By definition, L is *LTT at most* s in size if and only if the following holds.

There is a list Ps of *profiles* over α such that *sum*(*map*(*size*, Ps)) ≤ s and L = (the set of words w over α such that there is P ∈ Ps such that w ∈ *profile language*(P)).
