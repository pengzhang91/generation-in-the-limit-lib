## *accepts trace*

Let ι be a type. Let M be a *recognizer*. Let code be an embedding of ι into ℕ. Let x be a word over ι. Let tr be a *trace*.

By definition, *accepts trace*(M, code, x, tr) if and only if the following holds.

*first*(tr) = *config mk*(*recognizer initial*(M), 0, *input tape*(code, x)) and *legal moves*(*first*(tr), *rest*(tr)) and *facts*(tr) ⊆ *table*(M).

## *identifies in limit*

By definition, learner *identifies in limit* target from x with denotation denote if and only if the following holds.
