## *detects hallucinations*

Let α be a type. Let D be a *detector* over α. Let C be a *language family* over α.

By definition, D *detects hallucinations* for C if and only if the following holds.

Let z ∈ ℕ. Let x be a *stream* over α.

Suppose that *presents*(x, C(z)).

Let G ⊆ α.

There is T ∈ ℕ, depending only on α, D, C, z, x and G, with the following property. For every t ≥ T, *detector correct at*(D, G, C(z), x, t).
