## *deterministic*

Let α and β be types. Let A be a function from words over α to β. Let xs be a word over α.

By definition, *deterministic*(A, xs) = *pure*(A(xs)).

[Lean definition](../../../GenLimit/Paper20_AgnosticLanguageIdentificationAndGeneration/Model.lean#L30) · `GenLimit.AgnosticLanguage.deterministic`

## *finite witness index*

Let α be a type. Let u be a bijection from natural numbers to elements of α. Let C be a *language family* over α. Let p be a *PMF* over α.

By definition, C has *finite witness index* for p under u if and only if the following holds.

There is M ∈ ℕ, depending only on α, u, C and p, with the following property.

Let i ∈ ℕ.

Suppose that *ordered word*(u, C(i), r) ∈ *support*(p) for every r < M.

Then C(i) ⊆ *support*(p).

[Lean definition](../../../GenLimit/Paper20_AgnosticLanguageIdentificationAndGeneration/GenerationUpper.lean#L25) · `GenLimit.AgnosticLanguage.FiniteWitnessIndex`

## *gen err*

Let α be a type. Let A be a *statistical generator* over α. Let p be a *PMF* over α. Let n ∈ ℕ.

By definition, *gen err*(A, p, n) = *probability*(*bind*(*samples*(p, n), (xs ↦ *map*(*mk*(xs), A(xs)))), (the set of pairs z in (List α) × α such that *snd*(z) ∉ *support*(p) or *snd*(z) ∈ *fst*(z))).

[Lean definition](../../../GenLimit/Paper20_AgnosticLanguageIdentificationAndGeneration/Model.lean#L39) · `GenLimit.AgnosticLanguage.genErr`

## *has supported tell tale*

Let α be a type. Let C be a *language family* over α. Let p be a *PMF* over α.

By definition, C *has supported tell tale* for p if and only if the following holds.

There is j ∈ ℕ with the following properties:
- j is *optimal* in C for p.
- There is a finite set T of elements of α such that T *is finite tell tale* for C(j) relative to *range*(C) and T ⊆ *support*(p).

[Lean definition](../../../GenLimit/Paper20_AgnosticLanguageIdentificationAndGeneration/Model.lean#L27) · `GenLimit.AgnosticLanguage.HasSupportedTellTale`

## *id err*

Let α be a type. Let C be a *language family* over α. Let A be an *identifier* over α. Let p be a *PMF* over α. Let n ∈ ℕ.

By definition, *id err*(C, A, p, n) = *tsum*((j ↦ *to real*(*coe*(*bind*(*samples*(p, n), A), j)) · (*risk*(p, C(j)) − *optimal risk*(C, p))), *unconditional*(*nat*)).

[Lean definition](../../../GenLimit/Paper20_AgnosticLanguageIdentificationAndGeneration/Model.lean#L32) · `GenLimit.AgnosticLanguage.idErr`

## *id p*

Let α be a type. Let C be a *language family* over α. Let A be an *identifier* over α. Let p be a *PMF* over α. Let n ∈ ℕ.

By definition, *id p*(C, A, p, n) = *probability*(*bind*(*samples*(p, n), A), {j ∈ ℕ : j is not *minimal optimal* in C for p}).

[Lean definition](../../../GenLimit/Paper20_AgnosticLanguageIdentificationAndGeneration/Model.lean#L36) · `GenLimit.AgnosticLanguage.idP`

## *is finite tell tale*

Let α be a type. Let H be a *language class* over α. Let L be a *language* over α. Let T be a finite set of elements of α.

By definition, T *is finite tell tale* for L relative to H if and only if the following holds.

All of the following hold:
- T ⊆ L.
- Let K ∈ H with T ⊆ K. Suppose that K ⊆ L. Then K = L.

[Lean definition](../../../GenLimit/Support/FiniteTellTale.lean#L14) · `GenLimit.Generic.IsFiniteTellTale`

## *minimal optimal*

Let α be a type. Let C be a *language family* over α. Let p be a *PMF* over α. Let j ∈ ℕ.

By definition, j is *minimal optimal* in C for p if and only if the following holds.

All of the following hold:
- j is *optimal* in C for p.
- Let k ∈ ℕ. Suppose that k is *optimal* in C for p. Then *s subset*(C(k), C(j)) does not hold.

[Lean definition](../../../GenLimit/Paper20_AgnosticLanguageIdentificationAndGeneration/Model.lean#L24) · `GenLimit.AgnosticLanguage.MinimalOptimal`

## *optimal*

Let α be a type. Let C be a *language family* over α. Let p be a *PMF* over α. Let j ∈ ℕ.

By definition, j is *optimal* in C for p if and only if *risk*(p, C(j)) = *optimal risk*(C, p).

[Lean definition](../../../GenLimit/Paper20_AgnosticLanguageIdentificationAndGeneration/Model.lean#L23) · `GenLimit.AgnosticLanguage.Optimal`

## *probability*

Let α be a type. Let p be a *PMF* over α. Let E ⊆ α.

By definition, *probability*(p, E) = *to real*(*coe*(*to outer measure*(p), E)).

[Lean definition](../../../GenLimit/Support/DiscreteIID.lean#L24) · `GenLimit.DiscreteIID.probability`
