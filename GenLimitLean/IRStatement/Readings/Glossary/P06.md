## *common intersection*

Let α be a type. Let H be a *language class* over α.

By definition, *common intersection*(H) = *class intersection*(H).

## *finite noisy closure dimension at*

Let α be a type. Let H be a *language class* over α. Let n ∈ ℕ.

By definition, H has *finite noisy closure dimension at* noise level n if and only if the following holds.

There is D ∈ ℕ, depending only on α, H and n, with the following property.

Let d ∈ ℕ.

Suppose that D < d.

Then *noisy closure witness at*(H, n, d) does not hold.

[Lean definition](../../../GenLimit/Paper06_NoisyExamples/Definitions.lean#L86) · `GenLimit.NoisyExamples.FiniteNoisyClosureDimensionAt`

## *UUS*

Let α be a type. Let H be a *language class* over α.

By definition, H is *UUS* if and only if the following holds.

Let L ∈ H.

Then L is *set infinite*.
