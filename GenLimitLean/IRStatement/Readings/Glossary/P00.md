## *abstract identifiable*

Let Name, Object and Info be types. Let naming be a *naming* over Name and Object. Let allowable be an *allowable* over Info and Object.

By definition, *abstract identifiable*(naming, allowable) if and only if the following holds.

There is a *learner* learner over Info and Name such that *identifies*(naming, allowable, learner).

## *collapsing uncertainty*

Let Info and Object be types. Let allowable be an *allowable* over Info and Object.

By definition, allowable is *collapsing uncertainty* if and only if the following holds.

Let target be an element of Object. Let x ∈ allowable(target). Let object be an element of Object.

Suppose that object ≠ target.

Then there is T ∈ ℕ, depending only on Info, Object, allowable, target, x and object, with the following property. For every t ≥ T, *compatible*(allowable, *text prefix*(x, t), object) does not hold.

## *distinguishable*

Let Info and Object be types. Let allowable be an *allowable* over Info and Object.

## *effective identifiable*

## *learns*

Let I, N and O be types. Let M be a function from words over I to N. Let names be a *denotation* over N and O. Let method be a *presentations* over I and O. Let C ⊆ O.

By definition, M *learns* C from method using names if and only if the following holds.

Let L ∈ C. Let s ∈ method(L).

There is an element n of N with the following properties:
- names(n, L).
- There is T ∈ ℕ, depending only on I, N, O, M, names, method, C, L, s and n, with the following property. Let t ∈ ℕ. Suppose that t ≥ T. Then M(*text prefix*(s, t)) = n.

## *limit translation*

Let A, B and O be types. Assume that A is *primcodable*. Assume that B is *primcodable*. Let src be a *denotation* over A and O. Let dst be a *denotation* over B and O. Let C ⊆ O.

By definition, src has a *limit translation* to dst on C if and only if the following holds.

There is a function g from A to B^ℕ with the following properties:
- g is *computable₂*.
- Let L ∈ C. Let a be an element of A. Suppose that src(a, L). Then there is an element b of B with the following properties:
  - dst(b, L).
  - There is T ∈ ℕ, depending only on A, B, O, src, dst, C, g, L, a and b, with the following property. Let t ∈ ℕ. Suppose that t ≥ T. Then g(a, t) = b.

[Lean definition](../../../GenLimit/Paper00_LanguageIdentification/Effective/Names.lean#L55) · `GenLimit.Gold.Effective.LimitTranslation`

## *two recursive translation*

Let src and dst be *name relations* over *code*. Let C be a set of *languages*.

By definition, src has a *two recursive translation* to dst on C if and only if the following holds.

There is a function R from (*code* × *code*) × ℕ to Bool^ℕ with the following properties:
- R is *computable₂*.
- Let graph = (a ↦ the property b ↦ there is w ∈ ℕ such that R(((a, b), w), u) = *true* for every u ∈ ℕ). All of the following hold:
  - Let a, b and c be *codes*. Suppose that graph(a, b). Suppose that graph(a, c). Then b = c.
  - Let L ∈ C. Let a be a *code*. Suppose that src(a, L). Then there is a *code* b such that graph(a, b) and dst(b, L).

[Lean definition](../../../GenLimit/Paper00_LanguageIdentification/Effective/IndexObstructions.lean#L123) · `GenLimit.Gold.Effective.TwoRecursiveTranslation`
