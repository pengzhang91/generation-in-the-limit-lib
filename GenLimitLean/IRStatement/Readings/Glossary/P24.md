## *gaussian generator*

Let X be a type. Let u be a bijection from natural numbers to elements of X. Let C be a *language family* over X. Let f ∈ ℕ. Assume that f is *ne zero*. Let n ∈ ℕ. Let s be a function from words over X to ({0, …, f − 1} → ℝ). Let ε and δ be real numbers.

By definition, *gaussian generator*(u, C, n, s, ε, δ) = *release*(u, C, n, *gaussian law*(s, 1, ε, δ)).

Let α be a type. Let A be a *statistical generator* over α. Let p be a *PMF* over α. Let n ∈ ℕ.

## *generation assumptions*

Let X be a type. Let u be a bijection from natural numbers to elements of X. Let C be a *language family* over X. Let p be a *PMF* over X.

By definition, *generation assumptions*(u, C, p) if and only if the following holds.

All of the following hold:
- There is W ∈ ℕ such that C has *witness by* W for p in u.
- There is i ∈ ℕ such that C(i) ⊆ *support*(p).

## *intersecting infinite difference pair*

Let X be a type. Let C be a *language family* over X.

By definition, C is *intersecting infinite difference pair* if and only if the following holds.

There are i ∈ ℕ and j ∈ ℕ with the following property. C(i) ∩ C(j) is *nonempty* and C(i) ∖ C(j) is *infinite* and C(j) ∖ C(i) is *infinite*.

## *intersecting private pair*

Let X be a type. Let C be a *language family* over X.

By definition, C is *intersecting private pair* if and only if the following holds.

There are i ∈ ℕ and j ∈ ℕ with the following properties:
- C(i) ≠ C(j).
- There is an element a of X with the following properties:
  - a ∈ C(i) ∩ C(j).
  - There is an element x of X with the following properties:
    - x ∈ C(i).
    - There is an element y of X with the following properties:
      - y ∈ C(j).
      - Let k ∈ ℕ with x ∈ C(k). Then C(k) = C(i).
      - Let k ∈ ℕ with y ∈ C(k). Then C(k) = C(j).

[Lean definition](../../../GenLimit/Paper24_PriceOfPrivacy/IdentificationLower.lean#L12) · `GenLimit.PriceOfPrivacy.IntersectingPrivatePair`

## *is private*

Let X and Y be types. Let ε be an *ENN real*. Let A be a function from words over X to *PMF*(Y).

By definition, A *is private* at ε if and only if the following holds.

Suppose that ε ≠ *top*.

Let pre be a word over X. Let x and y be elements of X. Let post be a word over X. Let F ⊆ Y.

Then *coe*(*to outer measure*(A(*h append*(pre, *cons*(x, post)))), F) ≤ *of real*(*exp*(*to real*(ε))) · *coe*(*to outer measure*(A(*h append*(pre, *cons*(y, post)))), F).

## *private at*

Let X and Y be types. Let ε and δ be real numbers. Let n ∈ ℕ. Let A be a function from words over X to *PMF*(Y).

By definition, A is *private at* ε with slack δ for sample size n if and only if the following holds.

Let pre be a word over X. Let x and y be elements of X. Let post be a word over X.

Suppose that (*length*(pre) + *length*(post)) + 1 = n.

Let F ⊆ Y.

Then *probability*(A(*h append*(pre, *cons*(x, post))), F) ≤ (*exp*(ε) · *probability*(A(*h append*(pre, *cons*(y, post))), F)) + δ.

## *witness by*

By definition, C has *witness by* W for p in u if and only if the following holds.
